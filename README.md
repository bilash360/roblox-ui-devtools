## 🌠 Why Luix Forge Exists

Roblox UI development has splintered into a beautiful but fragmented galaxy of frameworks. React-Luau offers declarative power, Roact brings legacy stability, Fusion delivers reactive elegance, and Vide champions minimalism. Each has its own dialect for props, its own conventions for children, and its own way of whispering to the renderer.

Luix Forge listens to all of them.

Instead of forcing you to memorize four separate mental models, Luix Forge builds a **unified semantic layer** on top of your workspace. When you hover a prop, you don't just see a type — you see how that prop flows through the component, where it lands in the rendered tree, and what sibling props typically accompany it. It is the difference between reading a dictionary and reading a novel.

## 🪐 Feature Galaxy

### 🔭 Prop Hints That Actually Understand Context
Every prop hint is generated from live analysis of your component definitions, not from a static lookup table. That means hints evolve as your codebase evolves. Rename a prop, and the hints follow. Add a variant, and the intelligence adapts.

### 🖱️ Hover Documentation With Depth
Hover over any component, prop, or style token and receive a structured documentation card including:
- Inferred type signatures
- Usage frequency across the project
- Example snippets drawn from your own code
- Cross-framework equivalents (e.g., how a Roact prop maps to a Fusion equivalent)

### 🎨 Color Pickers With Palette Memory
Inline color pickers appear wherever a color value is expected — whether hex, RGB, or theme token. The picker remembers your project's palette and suggests recently used colors, harmonized tones, and accessible contrast pairings.

### 📜 RichText Tooling That Respects Roblox Syntax
RichText strings are notoriously easy to break. Luix Forge validates tags in real time, previews formatted output, and warns about unsupported nesting before your game ever runs.

### 🖼️ Asset Preview Without Leaving the Editor
Hover over any `rbxassetid://` reference and see a thumbnail preview rendered locally. No need to open a browser, no need to upload placeholder assets just to check a decal.

### 🧠 Cross-Framework Intellisense
Type a prop in a Fusion component and receive hints that include how the same concept is expressed in Vide. Learn frameworks by osmosis, not by documentation dives.

### 🧩 Component Tree Visualizer
A side panel that renders your component hierarchy as an interactive tree, updated live as you edit. Click any node to jump to its definition.

## 🖥️ Responsive UI & Adaptive Workspace

The Luix Forge panel reshapes itself to fit your editor layout. On ultrawide monitors, it unfolds into a three-column dashboard. On laptops, it collapses gracefully into a single intelligent pane. On tablets used for remote development, it becomes a touch-friendly inspector.

The experience is *fluid* — not just visually responsive, but contextually responsive. When you switch from a Roact file to a Fusion file, the entire panel reconfigures to match the idioms of that framework.

## 🌍 Multilingual Authoring Support

Luix Forge understands that Roblox developers span the globe. The interface and documentation cards are available in multiple languages, including English, Spanish, Portuguese, French, German, Japanese, Korean, and Simplified Chinese. Locale detection is automatic, but always overridable.

Prop hints themselves remain in the source language of your codebase, but explanatory annotations can be displayed in your preferred reading language — a subtle but powerful bridge for international teams.

## ⚙️ Configuration & Preferences

Luix Forge ships with sensible defaults, but every meaningful behavior is configurable:

- Toggle hover documentation verbosity (compact / standard / verbose)
- Enable or disable cross-framework hint mapping
- Choose preferred color picker mode (hex, RGB, HSL, token-first)
- Set RichText validation strictness
- Configure asset preview thumbnail size and caching
- Select interface language and fallback locale
- Define per-framework overrides for hint behavior

Configuration lives in your workspace settings, so teams can share a consistent intelligence profile across machines.
